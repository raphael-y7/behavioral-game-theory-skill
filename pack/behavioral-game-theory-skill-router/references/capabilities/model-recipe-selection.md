# 模型选型菜谱（行为博弈论 · 总路由）

## R — 原文

> "有人喜欢直接看着菜谱烹饪。下面是我本人使用行为博弈理论的菜谱。如同许多食谱一样，它是个性化的……但它同时允许对配料进行替换，也无疑应该进行修补。"（第9章 9.1.7 末，合并稿 L4640 附近）
> "一个便捷的代入参数的方式（好比是零卡路里的菜谱）：试试 β=0，α=1/3。"（第9章，FS 条目）

## I — 自述

这是作者在全书结尾给出的**模型选择总决策框架**：遇到一个策略互动问题时，先判断问题的类型，再按类型取用对应的模型、默认参数与替代方案。三条主分支是：①关心社会性偏好（人们在意公平/互惠）→ 用 FS 规避不均等模型（默认 α=1/3、β=0），替代品是 ERC、拉宾互惠；②关心首轮/未适应行为（新博弈、新参与者第一次怎么选）→ 用认知等级 CH（泊松 τ=1.5），替代品是 QRE；③关心重复互动中的学习演化 → 用函数形式 EWA/fEWA（λ=1），替代品是加权虚拟行动或带 PV 的强化模型。使用铁律：默认参数是"零卡路里菜谱"（方便起步的约定值），不是实证定律——换场景必须重估。

## A1 — 案例（书中亲历）

类型：作者原版例题（第9章"菜谱"段，c41）。作者对三类问题各给出完整公式与默认参数：工资设定/税收/公共物品 → FS 的 $U_i(X)=x_i-\frac{\alpha}{n-1}\sum\max(x_k-x_i,0)-\frac{\beta}{n-1}\sum\max(x_i-x_k,0)$，代入 α=1/3、β=0；首轮行为 → CH 的泊松分布 f(k|τ)=e^{−τ}τ^k/k!（原书排印漏负号，验证已裁定）取 τ=1.5；学习 → fEWA 更新式取 λ=1。作者自述"允许配料替换"，并逐条给出替代模型名。结果：作者本人声明该菜谱"个性化"，未承诺普适——这本身就是用法边界。

## A2 — 未来触发

1. 情境：用户面对一个策略互动问题（对手行为、多方博弈、市场参与者反应），不知道该用博弈论的哪个工具/模型切入。
2. 语言信号："该用哪个模型""有没有现成框架""博弈论怎么分析 X""participants 会怎么反应""帮我选个博弈模型""first mover 会怎么想"。
3. 相邻区分：本卡是**路由与选型**，只负责"选哪个模型+默认参数"，不负责具体计算（计算归各专业卡：社会性偏好计算→social-preference-measure；首轮预测→cognitive-hierarchy-first-round；学习建模→ewa-learning-model）。若用户已明确模型、只要数值，直接走专业卡。

## E — 执行步骤

1. **判定问题类型**（完成标准：三选一落定，或明确判定"不是策略互动问题"）：
   - 问题核心是"人们是否/如何在意他人所得"→ 分支 A（社会性偏好）；
   - 问题核心是"第一次互动/新环境下人们怎么选"→ 分支 B（首轮行为）；
   - 问题核心是"随重复交互行为如何变"→ 分支 C（学习演化）。
2. **取用分支卡**：A → 读 social-preference-measure 卡执行 FS/互惠计算；B → 读 cognitive-hierarchy-first-round 卡执行 CH/QRE 计算；C → 读 ewa-learning-model 卡执行 EWA 更新。
3. **套默认参数起步**：α=1/3、β=0；τ=1.5；λ=1（完成标准：参数表随输出一并列出）。
4. **判停与替换**：若所选模型对当前问题给出明显反直觉结论，查该分支卡的"替代模型"清单（A：ERC/拉宾；B：QRE；C：加权虚拟行动/PV 强化）；若问题涉及均衡选择/信号/声誉/进入/谈判，改走 coordination-selection / signal-reading / reputation-mechanism / market-entry-dynamics / bargaining-prediction 卡。
5. **输出契约**：输出含三部分——选型结论（分支+模型名+理由）、默认参数表、替代方案一行；不输出与选型无关的推导。

## B — 边界

- 默认参数（α=1/3、τ=1.5、λ=1）是作者自认的"零卡路里菜谱"，非实证定律；用于真金白银的大额决策前必须重估（反例 x31，第9章原话）。
- 作者自认本菜谱"个性化、使用自制配料"，其学习分支偏向作者自创的 EWA（第9章 9.1.5 原话承认立场偏向）。
- 不要用本卡处理：单人不涉及互动的决策（那是普通决策分析）；已由市场选择充分塑造的长期均衡价格（实验室规律外推边界，见 BOOK_OVERVIEW 批判节）。
- 本卡不替代专业卡的计算；拿它直接算数是误用。
