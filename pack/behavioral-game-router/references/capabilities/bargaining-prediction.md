# 讨价还价结果预测（router 卡）

## R — 原文

> "忽略份额少于 δ/(1+δ) 的外部选择的非合作均衡被称为'选择排除'（deal-me-out）解……'选择排除'的预测要远优于'分割差额'。"（第4章 4.2.4，宾莫尔等实验；排印疑误已由验证裁定为 δ/(1+δ)，47% 数值双重印证）
> "出价和还价通常介于待分金额的均等分割和精炼子博弈的预测值之间。"（第9章 9.1.3，合并稿 L4650 附近）

## I — 自述

预测一场谈判会落在哪里的流程卡。总原则先行：真实结果几乎总落在"均分"与"精炼子博弈完美预测"构成的区间内（9.1.3）。核心判据是**外部选择的三分法**：外部选择份额 < δ/(1+δ)（δ 为贴现因子）→ deal-me-out 解，外部选择无关，按轮流出价均衡分（份额 δ/(1+δ) 与 1/(1+δ)）；外部选择高于该阈值且威胁在均衡中真会被执行 → 影响分配（可信威胁原则）；外部选择由外生强制触发（如法院裁决）→ 例外，直接影响分配。再叠加行为修正：公平偏好把结果拉向均分、两轮以上博弈出现"两轮截断启发式"（把第3期当成结束）、截止期前最后几分钟才成交（信息传递解释）、自利性偏向使双方对"公平点"的判断都偏向自己（可用"弱点列示"去偏）。

## A1 — 案例（书中转述）

类型：实验案例（c21，第4章 4.2.4）。Binmore 等 1991：7 英镑的饼、外部选择 0/2/4 英镑三档、δ=0.9。deal-me-out 预测参与者 2 得 47%/47%/57%，split-the-difference 预测 47%/64%/76%——实测协议尖峰在 50% 与 57%，deal-me-out 大胜：低外部选择不改变分配（"选择排除"），高外部选择按占比进入。
类型：实验案例（第4章 4.2.3，罗思-莫洛夫彩票实验，c20 相关）。二元彩票讨价还价：参与者对彩票分配谈判，协议密集于"均分美元期望支付"而非均分彩票——对仿射变换的独立性公理被干净拒绝，公平锚定在货币而非筹码上。

## A2 — 未来触发

1. 情境：并购/大宗交易/薪酬/租金/和解谈判的落点预估；判断"对方手里的 BATNA 到底重不重要"；设计谈判时序与截止期；预测僵局率。
2. 语言信号："这单能谈到多少""BATNA/底牌""谈判筹码""会不会谈崩""bargaining / outside option / walk-away"。
3. 相邻区分：与 social-preference-measure 的区别——本卡是流程与区间预测，公平偏好的效用计算在那边做（本卡直接引用其结论"拉向均分"）；与 signal-reading 的区别——谈判中的信息传递（罢工模型）仅在"说真话约束"处引用信号结论；与 coordination-selection 的区别——多聚点谈判（如 A 牌聚点）用本卡的聚点条目，平台/标准之争归协调卡。

## E — 执行步骤

1. **输入契约**：饼的大小、贴现因子 δ（或每轮成本/固定延迟成本，按 δ=1/(1+r) 换算）、双方外部选择、轮数结构、谁先出价。缺 δ 或外部选择时先问（判停点）。
2. **算精炼基准**：轮流出价 SPE 份额（先出价者 δ/(1+δ)）；有限轮用逆向归纳。
3. **套三分法**：比较各方外部选择与 δ/(1+δ)×饼——低于→deal-me-out（外部选择出局）；高于且威胁可信→并入威胁点重算；外生强制→直接计入。（完成标准：每方外部选择一行"计入/排除"判定）
4. **行为区间修正**：输出"均分 ↔ 精炼预测"区间而非点值；公平偏好强（公开/亲属/重复关系）→ 偏均分端；匿名/高竞争→ 偏精炼端。
5. **期限修正**：截止期效应（最后 9-12 分钟成交密集）+ 两轮截断启发式（轮数≥3 时按"再谈一轮"直觉）。
6. **输出契约**：参数表 | deal-me-out/split 区间 | 行为修正后的预测区间 | 僵局概率提示（不协调率随结构参数的公式 p229 可选）| 谈判设计建议（截止期/信息结构）。

## B — 边界

- deal-me-out 的适用前提是"威胁在均衡中不会真被执行"；对外生强制终止（法院、监管裁定）不适用——那是本书明确的例外（p246/p247）。
- δ/(1+δ) 是裁定后的正确形式（译本 δ/(1−δ) 为排印错误）；引用公式时按修正值并注明。
- 完全信息实验的规律不能直接搬进不对称信息谈判（双重失效例：x16 条目——选择性接受与信息传递同时出问题）。
- 公平区间预测不适用于零和投机盘（对手不是谈判伙伴而是交易对手方，格劳乔·马克斯逻辑适用）。
- 自利性偏向是双向的：双方都觉得对自己公平才公平——预测僵局时先查双方"公平点"是否错位（f219 诊断流程）。
