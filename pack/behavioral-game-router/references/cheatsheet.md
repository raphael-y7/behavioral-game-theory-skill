# 决策规则速查 — 行为博弈：对策略互动的实验研究

| 能力 | 一句话规则 |
|---|---|
| 模型选型菜谱（行为博弈论总路由） | 先判问题类型（偏好/首轮/学习），再取对应模型+默认参数+替代方案 |
| 社会性偏好测度与计算（FS/互惠） | 用独裁者/最后通牒/信任博弈测偏好，用 FS 函数把"在意差距"算进效用再重求均衡 |
| 认知等级与首轮行为预测（CH/QRE） | 人群按泊松 τ≈1.5 分层逐步推理，预测首轮落点用 CH 加权，理性程度用 QRE 的 λ 定价 |
| EWA 学习建模（含机制辨识） | 吸引力 A 与权重 N 按 φ/δ/κ 三参数更新，δ=0 退化强化、δ=1 退化信念学习，fEWA 把参数函数化到只剩 λ |
| 协调博弈与均衡筛选（聚点/风险占优） | 先三分类（匹配/猎鹿/性别战），再按聚点原则、风险度量（闪点0.67-0.75）与交流/指定/时序判据筛选均衡 |
| 信号传递判读（含企业融资信号） | 信号必须"某些类型承受得起、另一些过于昂贵"；均衡识别后按弱精炼筛选，强精炼失灵 |
| 市场进入与拥挤判断 | 算均衡进入人数与概率，再按"方差缩小+基准组群忽视"两修正预判拥挤与整体亏损 |
| 声誉机制与承诺可信度 | 声誉=类型概率的贝叶斯积累与消耗：阈值路径逐期前移，一次拖欠永久失格 |
| 讨价还价结果预测 | 结果落在"均分↔精炼预测"区间；外部选择低于 δ/(1+δ)×饼则出局（deal-me-out） |
| 行为实验研究审计 | 过五因素清单（激励/匹配重复/匿名蒙蔽/描述语境/结构），反直觉结果按"重复→奖金→匿名→描述"四步归因 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
