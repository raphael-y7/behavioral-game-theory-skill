# 认知等级与首轮行为预测（CH/QRE）

## R — 原文

> "$f(0\mid\tau)$ 比例的参与者对 h 个策略进行随机化选择。对大于 0 的整数 k……$f(k\mid\tau)$ 比例的人以概率 $P_k(s^i)=I(s^i,\ s_k^*)$ 选择策略 $s_i$"（第9章菜谱 CH 条目，合并稿 L4656-4659；泊松式按验证裁定为 e^{−τ}τ^k/k!）
> "多数研究显示，参与者使用二至三级的重复占优。"（第9章 9.1.4，合并稿 L4650 附近）

## I — 自述

预测"第一次博弈/新环境下人们怎么选"的工具。核心事实：人不是无限推理者——跨选美比赛、专利竞争、蜈蚣、邮件博弈等大量实验，人群的推理深度呈泊松分布，均值约一步半（τ≈1.5）。CH 模型把总体分成 k=0,1,2,… 级：0 级随机选；k 级对"0 到 k−1 级的标准化分布"做最优反应（只多想一步）。预测选择概率 = 各级概率加权。配套工具 QRE（随机最优反应均衡）：对期望支付做 Logit 噪声，唯一参数 λ 控制理性度（λ=0 等概率、λ→∞ 纳什），是"给理性程度定价"的单参数均衡概念。两者合用：CH 管"第一步落点"，QRE 管"整张概率分布的理性度量"。经验锚点：p-选美比赛中位数推理步数=2，二至四级各占约 10%+；书内高群体（CEO、报读者）也只到 0–3 级。

## A1 — 案例（书中转述）

类型：实验案例（c06+c07，第1章 1.2.2-1.2.3）。选美比赛：目标是选"最接近平均数 2/3 倍"的数字。0 级随机（均值 50）→1 级选 33→2 级选 22→均衡 0。真实学生群体首轮中位数落在 2 步推理（约 22）而非 0——推理停在第二步。作者亲历（c07）：加州理工理事会把 18.1 美元拍出（=17.5+0.6，两步推理），在场全是博弈论老手——"聪明人也就多想一步"。泡沫含义（x29）：即使人人预见崩盘，"比别人早一步"而非"立即离场"才是均衡策略。
类型：纸面演练（验证 V2，p337）。τ=1.5：f(0|τ)=e^{−1.5}=0.223，f(1)=1.5·e^{−1.5}=0.335，f(2)=0.251——0/1/2 级合计约 81%。新输入 τ=2.0 → f(0)=0.135，f(1)=0.271，f(2)=0.271（演练记录见 verify_B_principles.md）。

## A2 — 未来触发

1. 情境：新标的/新规则/新题材首轮定价；预判"市场第一反应"落在哪一级推理；判断对手盘的思考深度；设计/评估需要对手"想几步"的策略。
2. 语言信号："第一反应""开局怎么选""大家会先想到什么""几步推理""market first reaction""level-k / beauty contest / depth of reasoning"。
3. 相邻区分：与 ewa-learning-model 的区别——本卡只管"第一期/未学习"落点，重复之后的演化归 EWA；与 model-recipe-selection 的区别——那是选型路由，本卡是分支 B 的具体计算器；与 coordination-selection 的区别——多重均衡筛选（聚点）不归本卡。

## E — 执行步骤

1. **输入契约**：策略集合与支付矩阵（或支付函数）；若做 CH，还需判断"随机化基准"h 个策略；缺支付矩阵时先问，不得臆造数值。
2. **定 0 级基准**：按原书规则——0 级对 h 个策略均匀随机（完成标准：明确写出 0 级分布）。
3. **CH 逐级计算**：f(k|τ)=e^{−τ}τ^k/k!，τ 默认 1.5（泊松，原书排印漏负号，一律用 e^{−τ}）；k 级最优反应 s_k*=argmax Σ π_i(s^j,s^m)·[Σ_{c<k}f(c)P_c(s^m)/Σ_{d<k}f(d)]；预测概率 P(s_i)=f(0|τ)/h+Σ_{k=1}^{8}f(k|τ)P_k(s_i)（完成标准：给出 0–2 级概率与最可能的策略落点）。
4. **QRE 备选**：P_j=e^{λy_j}/Σ_k e^{λy_k}，λ 默认按书内估计区间 0.25–3.2 试算；λ→∞ 与纳什对照（完成标准：λ 取两个值的两张概率表）。
5. **判停**：若问题涉及重复多期 → 停止，转 ewa-learning-model；若涉及均衡选择 → 转 coordination-selection。
6. **输出契约**：等级分布表 | 各级最优反应 | 加权预测落点 | 与纳什预测的差异 | 泊松参数 τ 取值声明。

## B — 边界

- τ=1.5 是"零卡路里默认值"（作者原话），不同人群/激励下须重估；CEO 与 FT 读者实测也只 0–3 级，但大额真金白银场景未系统测量。
- CH 预测的是"第一步"：把它用在已重复多次的稳态互动是误用（那时应看学习/均衡）。
- 选美博弈的均衡解 0 对人是坏选择（glossary 特别标注）——不要把"理性均衡=0"当作对真实人群的预测。
- 书中 CH/QRE 的比较优势结论部分出自作者自己（EWA/CH 作者立场偏向，9.1.5 原话）；独立比较文献更挑剔。
- 本卡不含"多走一步"之外的博弈树逆向归纳任务（蜈蚣/邮件的长链推理有专门结构，见 f312/f310/f316 正典条目所在章）。
