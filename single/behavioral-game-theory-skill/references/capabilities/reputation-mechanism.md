# 声誉机制与承诺可信度（router 卡）

## R — 原文

> "具有'强能力声誉'的参与者，也就是那些之前接受相对有利的协议的人，在与新的实验对象对抗时最终仍得以达成对己有利的协议。外生形成的声誉决定了以后的均衡分配。"（第4章 4.1，罗思与斯库马克尔实验，合并稿 L1834 附近）
> 声誉阈值路径：偿款概率 P_t=τ^n（τ≈0.789^(9−t) 结构，第8章 8.3，p625/p626 正典条目）

## I — 自述

跨期互动中"类型概率"如何被建立、维持与消耗。结构（借者-贷者范式）：借者可能是"诚实型"（概率先验）或"机会型"；贷者按后验决定是否再贷。均衡的关键结构是**阈值路径**：从末端倒推，"维持声誉"的行动阈值逐期前移（τ^n 形式），机会型参与者以维持贝叶斯更新的混合策略"养"声誉——直到临近终点才背离；一旦拖欠，类型被识破，永不再贷（声誉是一次性消耗品）。三个基本效应：先验概率决定养声誉的年限、短期博弈更接近"不伪装"、博弈变长声誉投资变多。配套修正：**自生先验**（homemade prior）——实验对象用自己的耐心/风险偏好猜对手类型，导致系统性误判，须先估出他们的"自造先验"再修正预测。应用：管理层信用记录、保兑承诺、平台惩罚制度的可信度评估。

## A1 — 案例（书中转述）

类型：实验案例（c39，第8章 8.3 借者-贷者声誉实验）。Camerer-Weigelt 设计：借者先验诚实概率 1/3，8 期贷款链；实测早期偿款率显著高于机会型混合策略预测（0.789^(9−t) 的零参数路径与数据吻合，第 7 期偿款率 0.4395 → 拖欠 0.5605 与原文 0.560 精确吻合，verify_B_principles V2 演练复核）；贷者对"前几期准时"的借者持续放贷，一次拖欠后永久停止。
类型：实验案例（第4章 4.1，罗思与斯库马克尔）。外生声誉实验：先让参与者和计算机谈判形成"强能力声誉"历史记录，再与真人谈判——带强声誉者拿到更有利分配，声誉是可携带的均衡资产。

## A2 — 未来触发

1. 情境：评估管理层/平台/对手"信用记录"的价值与脆弱性；判断"一直守信的人这次会不会守信"；设计或解读惩罚制度（一次违规永久拉黑 vs 渐进降权）；判断承诺期越长越可信还是越危险。
2. 语言信号："信用/声誉/口碑""track record""这次他敢不敢违约""承诺可信吗""reputation building / trust"。
3. 相邻区分：与 signal-reading 的区别——信号是单期信息含量，声誉是跨期类型概率的积累与消耗；一次公告归信号卡，"多年记录怎么估值"归本卡。与 social-preference-measure 的区别——不引入公平偏好，默认类型+贝叶斯结构。与 ewa-learning-model 的区别——学习是"策略吸引力的更新"，声誉是"类型信念的贝叶斯更新+阈值策略"。

## E — 执行步骤

1. **输入契约**：类型先验（诚实/有能力概率）、互动剩余期数或无限重复结构、每期行动的短期收益差、对手可观察的历史。缺先验或缺期数结构时先问（判停点）。
2. **建阈值路径**：从终期倒推每期的"维持声誉行动阈值"，写出 τ^n 型概率路径（τ 由支付结构反推；书中贷例 τ=110/140≈0.786）。
3. **算混合策略**：机会型每期以"维持后验不变"的混合概率养声誉；给出各期偿款/履约概率表（完成标准：路径表覆盖全部期数）。
4. **自生先验修正**：判断对手是否可能用自己的偏好猜类型（f618 排障条目），若是，先估自造先验再修正预测。
5. **评估声誉资产**：当前记录对未来的价值=类型后验的改善量；一次违约的代价=后验跳变后的永久阈值变化。
6. **输出契约**：类型先验与后验表 | 各期阈值/混合概率路径 | 声誉资产估值 | "何时背离"的结构性预测 | 自生先验风险提示。

## B — 边界

- 声誉=类型概率的贝叶斯结构，不是道德口碑（glossary 特别标注）；用"人品好"替代"类型+激励结构"会算错。
- 零参数预测 τ^n 的成功是本书最大胆的拟合之一，但来自特定支付结构（贷款链）；换结构须重推 τ。
- 短博弈中伪装收益低，行为更接近"不伪装"——不要用"长期才会装"套短期互动。
- 书中证据为学生被试、3-8 期小博弈；公司层面声誉还受媒体、监管、集体记忆影响，阈值结构外推需重估。
- 识别"教导"动机：若对手在故意塑造你的信念（策略性教导，f622 条目），贝叶斯更新本身可被操纵——这是本卡与老练学习的交叉边界。
